* **Program Purpose**: Calculates the total accumulated amount and compound interest based on principal, annual rate, compounding frequency, and years.
* **Input**: Principal amount, interest rate (as a percentage), compounding frequency per year, and investment duration in years.
* **Output**: Displays the final total amount and total compound interest formatted to two decimal places.
* **Execution**: Compile using a C compiler with the math library flag (`gcc main.c -o main -lm`), run the executable, and enter the requested values when prompted.
