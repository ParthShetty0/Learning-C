## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/Learning-C.git
```

### 2. Navigate to the directory

```bash
cd Learning-C
```

### 3. Compile a C program

Using GCC:

```bash
gcc filename.c -o program
```

### 4. Run the program

On Linux/macOS:

```bash
./program
```

On Windows:

```bash
program.exe
```
